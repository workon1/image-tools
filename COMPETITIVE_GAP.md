# Competitive gap

Compared conceptually with typical free image utilities (iLoveIMG-class suites, `imagetools.app`, `imagetools.to`). This is not a scrape of their copy.

## Where this product is already stronger

- **Privacy:** processing is local; competitors often upload
- **Honest compressor:** slider is target **file size %**, not fake “quality 50”
- **No account, no watermark**
- **Small JS surface** (no encoder WASM stack)

## Where competitors usually win

| Gap | Their typical offer | This repo (pre-fix) | Response |
|-----|---------------------|---------------------|----------|
| SEO pair coverage | Full JPG/PNG/WebP matrix | Missing PNG↔WebP pages | Add those two pages |
| Rotate / flip | Standard | Missing | Add canvas rotate tool |
| EXIF strip as a named tool | Common search | Implicit only | Dedicated page |
| HEIC from iPhone | Often server or WASM | Unsupported | Do not advertise; P3 later |
| Batch zip | One click | Per-file download | P2 |
| Domain trust | Own `.app` / `.com` | `*.vercel.app` | Buy domain (ops, not code) |
| Ad density | Aggressive | None | Keep tools unblocked |

## Opportunity

Lead with “files never leave this device” on every landing page, then match the **high-intent pair URLs** people already search. Do not copy competitor layouts or keyword-swap FAQs.
